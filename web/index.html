Drag the pointer across the keys in either direction or tap any key individually. Each contact triggers exactly one string; muted guitar strings remain silent. No synthesized extra strum notes. Keyboard, left to right: A S D F G H J K L ; ' Z X C V B.

UPSTREAM DSP runs Clipper’s MIT-licensed fixed-point string model in WASM on the audio thread, with our own 14-voice adapter and exploratory tones. TEMP WEB AUDIO keeps the original JS sound available. This is an instrument simulator; FM-1 CPU, pressure and LEDs remain unverified.
